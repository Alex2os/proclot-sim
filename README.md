\### release build

we can use:
"dotnet publish -c Release" in the MyAp folder (main folder) to build the release version, which can be shared or distributed.



also, we can use:

"dotnet publish -c Release -p:AssemblyName=appname -p:OutputName=appname" to change the name of the output files, like appname.dll, appname.exe, etc. also remember that you can change the name of the .exe without any problem, but changing the name of the dlls or other files might cause problems.
