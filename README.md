# ProcLot Sim
Proclot Sim is a multiplatform application to simulate and see how the processes work like when using the Round Robin (RR) algorithm.

## Features
<ul>
  <li>You can add as many processes as you want to the program and set their quantum.</li>
  <li>Processes have a name, operation to do (sum, multiplication, division, subtraction, module and power of), an ID (which is unique to each process) and a time. All of them can be set manually.</li>
  <li>If you don't want to add them manually, you can select a number of processes to be randomly added, including their quantum. All operations will be random.</li>
  <li>When starting the program, you will see three sections for the current processes: blocked, ended and ready.</li>
  <li>You can use keyboard keys to manipulate processes, like sending them to blocked, ending them immediately or adding more processes.</li>
  <li>You can see a table of processes which shows their actual state and useful info like their times (waiting time, ending time, service time, etc.).</li>
  <li>You can pause the program manually.</li>
  <li>When the program ends, you can leave the simulation page to add new processes or change something, then start the simulation again.</li>
  </ul>
